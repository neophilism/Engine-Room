# Discovered repository versus measured development roadmap

GitHub synchronization imports real repositories and PR activity regardless of whether an approved plan has been mapped. A repository can have hundreds of merged PRs without a formally approved roadmap. Those PRs must not be divided by a manufactured denominator.

For repositories with no approved and mapped plan, the Portfolio Home and project comparison explicitly show **Not measured**. The progress glass instrument is not illuminated as a false 0%-complete reading. Such projects remain visible and their GitHub URLs are available.

When an approved plan and explicit GitHub PR mappings are imported, only verified merge timestamps contribute to roadmap completion. Sorting by completion places measured projects before unmeasured projects in both ascending and descending modes. Lifecycle state remains separate from build and release evidence.
