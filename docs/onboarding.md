# Engine Room onboarding

Start at **/about** for feature explanations and metric definitions. Next visit **/** to inspect approved roadmap progress. Continue to **/projects** for milestone, feature, and release-readiness evidence. **/operations**, **/releases**, **/alerts**, **/finance**, and **/users** reflect observations ingested from authorized external systems.

**Setup:** Run ordered database migrations, configure the GitHub App and installation, and import approved development plans. The Settings console has an explicit administrator credential gate; scheduled synchronization requires an external trusted scheduler. See docs/settings-automation.md.

**Reliability:** Dashboard calculations use recorded source evidence. Empty observations are not favorable results; missing production acceptance evidence does not mean acceptance passed.
